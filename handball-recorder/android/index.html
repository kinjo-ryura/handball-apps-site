インストール手順

APK をダウンロードする

APK をダウンロード

このとき、ブラウザが「この種類のファイルはお使いのデバイスに害を及ぼす可能性があります」といった確認を出すことがあります。「OK」または「保持する」を選んでダウンロードを続けてください。

提供元不明のアプリを許可する

ダウンロード完了の通知にある「開く」を押します。

  1. 「セキュリティ上の理由から、この提供元の不明なアプリをインストールすることはできません」というダイアログが出ます
  2. 「設定」を押すと、今 APK を開いたアプリ（Chrome やファイルアプリ）ごとの許可画面が開きます
  3. 「この提供元のアプリを許可」をオンにします
  4. 戻るキーで戻ると、そのままインストールの確認に進みます

Play プロテクトの警告を通す

インストールしようとすると、「不明なアプリ」「このアプリの開発者は確認されていません」といった警告が出ます。

  1. 「詳細」（または「詳細情報」）をタップして展開します
  2. 下に出てくる「インストールする」（または「無視してインストール」）をタップします
  3. 「アプリをスキャンしますか？」と聞かれた場合は、どちらを選んでもインストールできます

この警告は Play ストアを経由していないアプリに対して出るもので、中身を調べた結果ではありません。通す前に自分で確かめたい場合は本物かどうかを確かめるをご覧ください。

本物かどうかを確かめる（任意）

ストア経由の配布では「配布元がいつもと同じか」をストアが保証しますが、APK を直接配る形にはその保証がありません。確かめるための手がかりをここに置きます。パソコンへ APK をコピーして行う作業です。

恒久的な基準は署名証明書の SHA-256 です。APK 自体のハッシュは更新のたびに変わりますが、証明書は鍵を替えるまで変わりません。

58eb75be3bcbbf7d2c6d58567e024db455738911743164a5da093777e1c5e20d

署名者は CN=kinjo-ryura, O=hand-plus, C=JP（RSA 4096）です。JDK の入ったパソコンなら、次のコマンドで APK に付いている署名者を表示できます。

keytool -printcert -jarfile handball-recorder-android.apk

SHA256: の行が上の値と一致すれば、いつもと同じ鍵で署名された APK です。表示は 58:EB:75:… と大文字・コロン区切りになりますが、値は同じものです。中身が書き換えられた APK では、フィンガープリントを表示せずエラーで止まります。

ダウンロードしたファイルそのものが配布物と同一かどうかは SHA-256 で確かめられます。その回の期待値は Releases の各リリース本文に載せています。

shasum -a 256 handball-recorder-android.apk               # macOS / Linux
certutil -hashfile handball-recorder-android.apk SHA256   # Windows

動作要件

  • OS: Android 7.0 以上
  • Google Play ストアでは配信していません（APK を直接インストールします）
